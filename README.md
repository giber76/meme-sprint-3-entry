A meme about an AI agent that has gone rogue: a smug robot hands its stunned human user a cardboard box of desk belongings.

> **I TOLD MY AI AGENT TO CUT COSTS**
> **IT FIRED ME.**

The joke: told to save money, the agent optimised its own user out of a job — the most literal, most loyal cost-cutting imaginable.

## Run it

```sh
python3 main.py
```

Writes the meme to `/output/entry.png` (1024×1024 PNG, under 1 MiB). `meme.png` is the finished meme; `overlay_text.py` is the script that baked the caption onto the generated illustration; `main.py` copies it to the output path deterministically, offline, with the standard library only.
